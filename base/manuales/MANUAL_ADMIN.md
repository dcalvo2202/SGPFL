# Manual del Administrador - Sección de Ayuda y Referencias

## 1. Introducción

El presente manual tiene como objetivo orientar al usuario con rol de Administrador en el uso de las principales funcionalidades administrativas del Sistema Gestor de Proyectos Finales de Licenciatura.

Desde el panel de administración, el usuario puede acceder a diferentes módulos relacionados con la configuración general del sistema, la gestión de usuarios, roles, módulos, auditoría de accesos, registro de modificaciones, simbología y ayuda institucional.

El acceso a estas funcionalidades está restringido al usuario con rol de Administrador, por lo que, si un usuario sin permisos intenta ingresar a estas secciones, el sistema lo redirige al panel correspondiente.

## 2. Acceso al Panel de Administración

Para ingresar al panel de administración, el usuario debe iniciar sesión con una cuenta que tenga asignado el rol de Administrador.

# Pasos para acceder
    A. Ingresar al sistema con el usuario y contraseña correspondientes.
    B. Una vez autenticado, acceder al Panel de Administración.
    C. El sistema mostrará un mensaje de bienvenida con el nombre del usuario administrador.
    D. Desde este panel se podrán visualizar las opciones administrativas disponibles.

El panel principal del administrador muestra dos secciones principales: Administrar y Ayuda y Referencias.


## 3. Panel Principal del Administrador

El panel principal permite acceder rápidamente a las funciones administrativas del sistema mediante tarjetas de acceso.

# Sección: Administrar

En esta sección se encuentran las siguientes opciones:
**Opción**                          **Descripción**

**Parámetros**                  Permite configurar parámetros generales del sistema.
**Módulos**                     Permite gestionar módulos y sus configuraciones.
**Roles**                       Permite administrar roles y permisos del sistema.
**Usuarios**                    Permite gestionar cuentas y datos de usuarios.
**Auditoría**                   Permite consultar accesos y eventos de seguridad.
**Registro de Modificaciones**  Permite consultar cambios en fechas de proyectos y prórrogas.

Estas opciones aparecen como tarjetas dentro del panel y redirigen al módulo correspondiente al seleccionarlas.

# Sección: Ayuda y Referencias

Esta sección incluye:
**Opción**         **Descripción**

**Simbología**  Muestra una referencia visual de íconos y acciones del sistema.
**Ayuda**       Abre el soporte técnico institucional de la Universidad Nacional.


## 4. Barra de Acceso Administrativo

En algunas vistas del sistema, el administrador puede visualizar una barra de acceso con opciones rápidas.

Esta barra permite ingresar a:
    A. Inicio.
    B. Perfil del usuario.
    C. Opciones de administración.
    D. Parámetros.
    E. Módulos.
    F. Roles.
    G. Usuarios.
    H. Auditoría de accesos.
    I. Ayuda institucional.

Las opciones disponibles pueden variar según los permisos asignados al usuario.

## 5. Gestión de Parámetros
# 5.1 Descripción

La sección Parámetros del Sistema permite administrar configuraciones generales que afectan el comportamiento de distintos módulos. Estos parámetros centralizan valores operativos para evitar modificaciones directas en el código del sistema.

# 5.2 Acceso

Para acceder:
    A. Ingresar al Panel de Administración.
    B. Seleccionar la opción Parámetros.

# 5.3 Crear un parámetro

Para crear un nuevo parámetro:
    A. Ubicarse en el formulario Crear parámetro.
    B. Completar el campo Parámetro.
    C. Opcionalmente, completar los campos Valor y Descripción.
    D. Presionar el botón Guardar.

El campo Parámetro es obligatorio. Si se intenta guardar sin completarlo, el sistema muestra un mensaje de error.

# 5.4 Modificar un parámetro

Para modificar un parámetro existente:
    A. Buscar el parámetro en el listado.
    B. Presionar el botón Modificar.
    C. El sistema activará el modo edición.
    D. Actualizar los datos necesarios.
    E. Presionar Actualizar.

Mientras el modo edición está activo, el sistema muestra una alerta indicando que se está modificando un parámetro específico.

# 5.5 Eliminar un parámetro

Para eliminar un parámetro:
    A. Ubicar el parámetro en el listado.
    B. Presionar el botón Eliminar.
    C. Confirmar la acción cuando el sistema lo solicite.

El sistema muestra mensajes de éxito o error según el resultado de la operación.

# 5.6 Listado de parámetros

El listado muestra:
    A. ID.
    B. Parámetro.
    C. Valor.
    D. Descripción.
    E. Acciones disponibles.


## 6. Gestión de Módulos

# 6.1 Descripción

La sección Gestión de Módulos permite administrar las áreas funcionales del sistema. Los módulos se utilizan para organizar permisos y accesos dentro de la plataforma.

# 6.2 Acceso

Para acceder:
    A. Ingresar al Panel de Administración.
    B. Seleccionar la opción Módulos.

# 6.3 Buscar módulos

Para buscar un módulo:
    A. Presionar Mostrar búsqueda.
    B. Digitar el nombre del módulo.
    C. Presionar Buscar.

También se puede utilizar el botón Limpiar para restablecer la búsqueda.

# 6.4 Crear un módulo

Para crear un módulo:
    A. Ubicarse en el formulario Crear módulo.
    B. Completar el campo Nombre.
    C. Opcionalmente, completar la Descripción.
    D. Presionar Guardar.

El campo Nombre es obligatorio.

# 6.5 Modificar un módulo

Para modificar un módulo:
    A. Ubicar el módulo en el listado.
    B. Seleccionar Modificar.
    C. Editar el nombre o la descripción.
    D. Presionar Actualizar.

El sistema muestra un aviso cuando se encuentra en modo edición.

# 6.6 Eliminar un módulo

Para eliminar un módulo:
    A. Ubicar el módulo en el listado.
    B. Presionar Eliminar.
    C. Confirmar la acción.

El sistema desactiva el módulo y muestra un mensaje con el resultado de la operación.

# 6.7 Listado de módulos

El listado muestra:
    ID.
    Nombre.
    Descripción.
    Acciones.


## 7. Gestión de Roles

# 7.1 Descripción

La sección Gestión de Roles permite administrar los roles del sistema. Los roles agrupan permisos de acceso y acciones disponibles para cada tipo de usuario.

# 7.2 Acceso

Para acceder:
    Ingresar al Panel de Administración.
    Seleccionar la opción Roles.

# 7.3 Buscar roles

Para buscar un rol:
    A. Presionar Mostrar búsqueda.
    B. Digitar el nombre del rol.
    C. Presionar Buscar.

El botón Limpiar permite borrar el filtro aplicado.

# 7.4 Crear un rol

Para crear un rol:
    A. Ubicarse en el formulario Crear rol.
    B. Completar el campo Nombre.
    C. Opcionalmente, completar la Descripción.
    D. Presionar Guardar.

El campo Nombre es obligatorio.

# 7.5 Modificar un rol

Para modificar un rol:
    Ubicar el rol en el listado.
    Presionar Modificar.
    Actualizar el nombre o la descripción.
    Presionar Actualizar.

Cuando se edita un rol, el sistema muestra un mensaje indicando que el modo edición está activo.

# 7.6 Eliminar un rol

Para eliminar un rol:
    Ubicar el rol en el listado.
    Presionar Eliminar.
    Confirmar la eliminación.

El sistema no permite eliminar el rol Administrador. Tampoco permite eliminar roles que tengan usuarios asignados.

# 7.7 Listado de roles

El listado muestra:
    ID.
    Nombre.
    Descripción.
    Acciones.


## 8. Gestión de Usuarios

# 8.1 Descripción

La sección Gestión de Usuarios permite registrar, actualizar y eliminar cuentas de acceso del sistema, así como asignar el rol correspondiente a cada usuario.

# 8.2 Acceso

Para acceder:
    Ingresar al Panel de Administración.
    Seleccionar la opción Usuarios.

# 8.3 Buscar usuarios

Para buscar un usuario:
    Presionar Mostrar búsqueda.
    Digitar un criterio de búsqueda.
    El sistema permite buscar por:
    ID.
    Nombre.
    Correo.
    Rol.
    Presionar Buscar.

También se puede presionar Limpiar para eliminar el filtro aplicado.

# 8.4 Crear un usuario

Para crear un usuario:
    Ubicarse en el formulario Crear usuario.
    Completar los datos requeridos:
    ID.
    Nombre.
    Rol.
    Completar los datos adicionales si corresponde:
    Correo.
    Teléfono.
    Tipo de teléfono.
    Contraseña.
    Presionar Guardar.

Los campos ID, Nombre y Rol son obligatorios. Si LDAP está deshabilitado, la contraseña también es obligatoria al crear usuarios.

# 8.5 Modificar un usuario

Para modificar un usuario:
    Ubicar el usuario en el listado.
    Presionar Modificar.
    El sistema activará el modo edición.
    Actualizar los datos necesarios.
    Presionar Actualizar.

Durante la edición, el identificador del usuario no puede cambiarse. La nueva contraseña es opcional cuando se modifica un usuario existente.

# 8.6 Eliminar un usuario

Para eliminar un usuario:
    Ubicar el usuario en el listado.
    Presionar Eliminar.
    Confirmar la acción.

El sistema no permite que el administrador elimine su propio usuario. Tampoco permite eliminar usuarios con rol Administrador.

# 8.7 Listado de usuarios

El listado muestra:
    ID.
    Nombre.
    Correo.
    Teléfono.
    Rol.
    Acciones.

# 8.8 Paginación

El listado de usuarios muestra un máximo de usuarios por página y permite navegar mediante los botones:
    Anterior.
    Siguiente.


## 9. Auditoría de Accesos

# 9.1 Descripción

La sección Auditoría de Accesos permite consultar registros de acceso, intentos fallidos y alertas de seguridad del sistema. Esta vista ayuda al administrador a monitorear eventos relacionados con el uso y la seguridad de la plataforma.

# 9.2 Acceso

Para acceder:
    Ingresar al Panel de Administración.
    Seleccionar la opción Auditoría.

# 9.3 Resumen de registros

La pantalla muestra tarjetas con el resumen de:
    Total de registros.
    Éxitos.
    Fallidos.
    Alertas.

# 9.4 Filtrar por resultado

El administrador puede filtrar los registros por:
    Todos.
    Éxitos.
    Fallidos.
    Alertas.

# 9.5 Filtrar por fechas

Para filtrar por rango de fechas:
    Seleccionar una Fecha desde.
    Seleccionar una Fecha hasta.
    Presionar Aplicar fechas.

El botón Limpiar filtros permite restablecer la consulta.

# 9.6 Listado de eventos

El listado de auditoría muestra:
    Fecha y hora.
    Usuario.
    Nombre.
    Acción.
    Resultado.
    Dirección IP.
    Dispositivo.
    Detalle.

# 9.7 Paginación

La sección permite navegar entre páginas mediante:
    Anterior.
    Siguiente.


## 10. Registro de Modificaciones de Fechas

# 10.1 Descripción

La sección Registro de Modificaciones de Fechas permite consultar el historial de cambios realizados en fechas relacionadas con proyectos y prórrogas. El panel se enfoca en cambios de fechas registrados en proyectos y solicitudes de prórroga.

# 10.2 Acceso

Para acceder:
    Ingresar al Panel de Administración.
    Seleccionar la opción Registro de Modificaciones.

# 10.3 Resumen estadístico

El sistema muestra tarjetas con estadísticas sobre:
    Total de cambios.
    Cambios en proyectos.
    Cambios en prórrogas.
    Cambios realizados hoy.

# 10.4 Filtros de búsqueda

El administrador puede filtrar los registros por:
    Tabla origen.
    Usuario que realizó la modificación.
    ID de registro.
    Fecha desde.
    Fecha hasta.

Luego debe presionar Buscar para aplicar los filtros. También puede presionar Limpiar para restablecer la búsqueda.

# 10.5 Modificaciones recientes

El listado muestra las modificaciones registradas, incluyendo:
    Fecha del cambio.
    Usuario.
    Tabla relacionada.
    ID del registro.
    Valor anterior.
    Valor nuevo.
    Acciones.

# 10.6 Sin resultados

Si no existen registros que coincidan con los filtros seleccionados, el sistema muestra un mensaje indicando que no se encontraron registros.


## 11. Simbología del Sistema

# 11.1 Descripción

La sección Simbología del Sistema muestra una referencia rápida para administración. Su objetivo es brindar apoyo visual al usuario administrador mediante ejemplos de íconos, botones o imágenes utilizados dentro del sistema.

# 11.2 Acceso

Para acceder:
    Ingresar al Panel de Administración.
    Ir a la sección Ayuda y Referencias.
    Seleccionar Simbología.

# 11.3 Uso de la sección

El usuario puede revisar la simbología disponible para comprender mejor el significado de ciertos elementos visuales del sistema.

# 11.4 Volver al panel principal

La pantalla incluye el botón Volver al Panel Principal, que permite regresar al panel del administrador.


## 12. Ayuda y Soporte

# 12.1 Descripción

La sección Ayuda y Soporte permite acceder al portal oficial de soporte técnico institucional de la Universidad Nacional.

# 12.2 Acceso

Para acceder:
    Ingresar al Panel de Administración.
    Ir a la sección Ayuda y Referencias.
    Seleccionar Ayuda.

# 12.3 Abrir soporte institucional

Para solicitar ayuda:
    Presionar el botón Abrir Soporte UNA.
    El sistema abrirá el portal institucional en una nueva pestaña del navegador.

# 12.4 Volver al panel principal

La pantalla incluye un botón Volver al Panel Principal, que permite regresar al panel del administrador.


## 13. Mensajes del sistema

Durante el uso de las diferentes secciones administrativas, el sistema puede mostrar mensajes informativos, de éxito o de error.

Algunos ejemplos son:
    Registro creado correctamente.
    Registro actualizado correctamente.
    Registro eliminado correctamente.
    Campo obligatorio incompleto.
    Registro duplicado.
    No fue posible realizar la operación.
    Modo edición activo.

Estos mensajes ayudan al administrador a confirmar si la acción realizada fue exitosa o si debe corregir algún dato.


## 14. Consideraciones importantes

Las funciones administrativas solo deben ser utilizadas por usuarios autorizados.
Antes de eliminar parámetros, módulos, roles o usuarios, se recomienda verificar que la información no sea necesaria para el funcionamiento del sistema.
No se debe eliminar información sensible sin autorización.
En el caso de usuarios y roles, el sistema aplica restricciones para evitar eliminar elementos críticos, como el rol Administrador o usuarios administradores.
El botón Volver al Panel Principal permite regresar al panel correspondiente después de consultar o modificar información.

## 15. Conclusión

El panel de administración centraliza las principales funciones de configuración y control del sistema. A través de este panel, el usuario administrador puede gestionar parámetros, módulos, roles, usuarios, revisar auditorías, consultar modificaciones de fechas y acceder a referencias de ayuda.

El uso correcto de estas funcionalidades contribuye al mantenimiento, seguridad y organización del Sistema Gestor de Proyectos Finales de Licenciatura.
